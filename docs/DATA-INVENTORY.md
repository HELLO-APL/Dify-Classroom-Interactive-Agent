# teach 数据清单：使用、获取、存储与需求

更新时间：2026-09-07

这份清单按“当前用到什么数据、AI 获取什么、AI 存储什么、AI 还需要什么、各方分别需要什么”分开整理，用于项目内部对齐数据边界。

## 1. 当前过程使用到的数据总览

| 数据对象 | 类型 | 谁产生 | 谁读取 | 存储位置 | 生命周期 |
| --- | --- | --- | --- | --- | --- |

## 2. AI/teach 当前“获取”的数据

每一轮对话，AI 实际获取：

- `student_message`：学生这一轮输入的文字；
- `file_input`：学生/老师本轮上传的文件，包括文件名、文件数量、可解析正文；
- `student_id`：当前固定为 `student-001`；
- `sessionId`：Chat Trigger 当前会话 ID，用来定位记忆；
- 规则文件：`class agent` 下所有 `.md`；
- 状态文件：`teach test` 下七个 md 的当前内容；
- 聊天记忆：同一会话内最近 20 轮对话；
- 模型上下文：由 n8n `Combine Context` 拼装后的规则 + 状态 + 当前输入。

老师端新材料 `teacher_material` 目前只是字段占位，Chat 输入界面还没有单独入口；网站、PDF、接口数据需要后续接入。

## 3. AI/teach 当前“存储”的数据

### 3.1 主动写入：七个状态 md

存放于：

```text
D:\project\Dify 课堂互动智能体\teach test
```

| 文件 | 记录什么 | 写入规则 |
| --- | --- | --- |
| `TMISSION.md` | 老师/全班目标、难点、易混淆点、反代答红线 | 老师内容为主，AI 不无证据改写 |
| `SMISSION.md` | 该学生的目标、成功样子、兴趣钩子、下一步、约束 | 只在出现学生证据后更新 |
| `NOTES.md` | 学生偏好与工作观察 | 只记偏好和工作观察 |
| `LESSON-INTERACTION.md` | 本课内容、易混淆点、任务、老师端输入 | 老师材料进入老师端输入区 |
| `GLOSSARY.md` | 已被真实证据支持的标准词条 | 有真实理解证据才写 |
| `LEARNING-RECORD.md` | 跨会话持久学习记录 | 有真实学习证据才写 |
| `DIALOGUE-LOG.md` | 会话控制、每轮证据、下次重点 | 每轮必须更新 |

### 3.2 平台自动存储

- n8n Simple Memory：同一 session 内最近 20 轮对话；
- n8n 执行日志：每次 Chat Trigger 的输入、LLM 输出、节点运行记录；
- DeepSeek 调用产生的 token 统计等 trace。

AI 不主动存储完整原始聊天记录；原始逐字对话只进入 n8n 记忆和执行日志，状态文件里存的是“证据化摘要”。

## 4. AI/teach 还需要的数据（目前缺口）

### 4.1 从老师/学生端补充

- 学生真实兴趣钩子：当前 `SMISSION.md` 中为空；
- 明确的课后作业/评价要求：当前只有根据 PPT 推断的建议任务；
- 图片内容的可读文本：最近上传的图片没有可解析文字，AI 无法从图片中获取证据；
- 更完整的“答对/答错样例”：供 TMISSION 中识别真实掌握证据使用。

### 4.2 从平台/工具端补充

- 真正的 `/research` 检索能力：当前只是占位说明，没有网页搜索或文件检索工具；
- 网站/接口材料读取能力：`teacher_material` 还没有实际拉取节点；
- 主动唤醒/定时器：未回应阶梯目前只能由外部事件触发；
- 可选：OCR 或图片理解，用于处理手写作业、截图、题目图片；
- 后续多学生时：按 `student_id` 分区存储与读写。

## 5. 各方数据需求

### 5.1 学生

需要获得：

- 一个当前最应该回答的问题；
- 回答后的确认、提示或进一步追问；
- 卡住时的可执行帮助；
- `/结束` 后的本课更新摘要。

需要提供：

- 回答/思考过程；
- 主动指令：`/wait-what`、`/research`、`/帮助`、`/结束`；
- 可选：作业文件、题目图片、兴趣点。

### 5.2 老师

需要获得：

- 学生当前卡点与已掌握内容；
- unresolved 难点和下一次建议；
- 每轮证据摘要、会话结束更新摘要；
- 后续可用的持久学习记录。

需要提供：

- TMISSION：老师目标、难点、易混淆点、答对/易错表现；
- LESSON-INTERACTION：本课内容和老师端材料；
- 作业、评价标准、反代答红线；
- 可选：SMISSION 中的学生个人目标与兴趣钩子。

### 5.3 AI/teach

需要获得：

- 当前学生消息与历史记忆；
- 老师规则；
- 学生状态；
- 老师端新材料；
- 会话标识。

需要存储：

- 有证据支持的七个状态 md；
- 当会话的逐字记忆；
- 工作流执行日志。

### 5.4 n8n/平台

需要获得：

- Chat 消息、sessionId、上传文件；
- 文件目录挂载权限；
- DeepSeek 凭据；
- 模型输入输出。

需要存储：

- 工作流定义；
- Simple Memory；
- 执行日志；
- 文件读写产生的状态 md。
