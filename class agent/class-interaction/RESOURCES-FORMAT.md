# RESOURCES Format

`RESOURCES.md` holds the trusted sources the class interaction may draw on.

## Template

```md
# {Topic} Resources

## Teacher materials
- [Title or source](URL or path)
  Use for: {when the AI should reach for it}

## Knowledge
- [Title or source](URL or path)
  Use for: {what it covers}

## Gaps
- {what no current resource covers}
```

## Rules

- Every entry needs a use note. A bare link cannot guide later sessions.
- Prefer primary sources and teacher-provided materials over model memory.
- If the class needs a resource that does not exist yet, write it under `## Gaps` rather than improvising content.
