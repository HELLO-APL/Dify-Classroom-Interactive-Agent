# LEARNING-RECORD Format

Learning records live in `learning-records/` and use sequential numbering: `0001-slug.md`, `0002-slug.md`, and so on.

A learning record captures durable, evidence-backed knowledge about this student: a corrected misconception, a demonstrated skill, or newly disclosed prior knowledge.

## Template

```md
# {short title of what was learned or established}

{1-3 sentences: what changed about what we know about this student and why it affects the next session.}

## Evidence
{what the student said or produced that backs this up}

## Implications
{what this unlocks or rules out next}
```

## Rules

- Write a record only on evidence. A session that covered material is not evidence of learning.
- When a later record contradicts an earlier one, mark the earlier record `Status: superseded by LR-NNNN` instead of deleting it.
- Keep records short. They steer future sessions; they are not session journals.
