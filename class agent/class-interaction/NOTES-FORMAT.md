# NOTES Format

`NOTES.md` is a scratchpad for the user's preferences and the agent's working notes, with the same position and role as in the matt teach workspace. It is not a student journal and not a dialogue transcript.

## Template

```md
# Notes

- {preference or working observation}
```

## Rules

- Record teaching preferences and working observations that should steer the next sessions.
- Read `NOTES.md` before a session so earlier preferences are honored.
- Move durable understanding out of `NOTES.md` into `learning-records/`.
- Keep dialogue evidence and transcripts in `dialogue-log/`.
