# LESSON-INTERACTION: 第3章 处理机调度（3学时）

## 学生已经会
- 进程的基本概念、PCB、作业与任务
- 进程状态及转换：运行、就绪、阻塞等
- 进程控制、进程创建与撤销
- 线程概念，以及线程与进程的区别
- 并发、并行、分时等基本概念

## 本课新内容
- 三级调度：高级调度（作业调度）、中级调度（内存调度/对换）、低级调度（进程调度）
- 进程调度的任务与机制：排队器、分派器、上下文切换
- 抢占式调度与非抢占式调度
- 调度目标与评价指标：周转时间、带权周转时间、平均等待时间、响应时间
- 作业调度算法：FCFS、SJF、优先级 PR、高响应比 HRRN
- 进程调度算法：FCFS、SJF、PR、RR、多级队列、多级反馈队列、公平调度
- 多处理机调度：SMP/ASMP、CPU 亲和性、负载均衡、公共/私有就绪队列
- 实时调度：调度条件、EDF、LLF、优先级倒置
- 调度实例：Linux CFS、Windows 线程优先级、鸿蒙 LiteOS 调度

## 易混淆点
- 高级调度 vs 低级调度
  - 区分问题: 一批作业还在外存等待，谁负责决定哪个作业进入内存；进入内存变成就绪进程后，谁负责决定哪个进程使用 CPU？
  - 正确表现: 高级调度（作业调度）选择作业并调入内存，低级调度（进程调度）从就绪进程中选择一个分配 CPU
- 非抢占式 vs 抢占式
  - 区分问题: 一个进程正在运行，另一个更高优先级进程到达，系统能否把 CPU 从当前进程手中拿走？
  - 正确表现: 非抢占式是进程运行完或自愿让出才切换；抢占式可以因时间片耗尽或更高优先级到达而中断当前进程
- FCFS vs SJF
  - 区分问题: 先到的长作业占用 CPU 很久，后续短作业只能排队等待，这描述的是哪种算法的主要问题？
  - 正确表现: FCFS 按到达顺序执行、对长作业公平但对短作业不利；SJF 按运行时间短的优先，平均等待时间更短但长作业可能饥饿
- SJF vs HRRN
  - 区分问题: SJF 只照顾短作业，为什么长时间等不到服务的长作业会饿死；HRRN 额外加入了什么条件让长作业有机会翻身？
  - 正确表现: HRRN 的响应比 = (等待时间 + 要求服务时间) / 要求服务时间，等待越久的作业优先级会自然上升，从而缓解饥饿
- 静态优先级 vs 动态优先级
  - 区分问题: 一个进程的优先级从创建到结束都不改变，和它相反的做法是什么？
  - 正确表现: 静态优先级固定不变；动态优先级会随等待时间、运行情况或系统反馈调整
- 多级队列 vs 多级反馈队列
  - 区分问题: 进程被分到某条队列后，还能因为运行表现移动到另一条队列吗？
  - 正确表现: 多级队列通常预先按性质分队列、进程不流动；多级反馈队列允许进程在不同队列间移动，不需要预先知道进程长度
- RR vs SJF
  - 区分问题: 想让每个就绪进程都能较快获得第一次响应，应该选谁；想让平均周转时间最短，又通常选谁？
  - 正确表现: RR 用时间片轮转，响应时间更短但平均周转通常更长；SJF 平均周转短，但可能让长作业等待过久
- 周转时间 vs 等待时间 vs 响应时间
  - 区分问题: 从作业提交到完成算的是哪个指标；只累计等待调度、不包含运行和 I/O 的是哪个；从提交到第一次获得响应的是哪个？
  - 正确表现: 周转 = 完成 - 提交；等待 = 累计等待 CPU 的时间；响应 = 从提交到首次得到响应/首次使用 CPU 的快慢
- EDF vs LLF
  - 区分问题: 两个实时任务都靠近截止时间，EDF 按什么排序；LLF 还多考虑了哪个因素？
  - 正确表现: EDF 按截止时间越早优先级越高；LLF 按松弛度（距截止时间的余量）排序，越紧张越优先
- 软亲和性 vs 硬亲和性
  - 区分问题: 系统是否允许一个进程被迁移到另一个 CPU 上运行？
  - 正确表现: 硬亲和性要求进程留在指定 CPU 集；软亲和性只是尽量留在原 CPU，必要时仍可迁移

## 本课任务或作业
- 老师提供的 PPT 和教学大纲中没有明确课后作业。根据 PPT 例题建议：
  - 给定作业/进程的到达时间和运行时间，分别用 FCFS、非抢占式 SJF、抢占式 SJF 画甘特图，并计算平均等待时间、平均周转时间
  - 用 RR 在时间片 q=1 和 q=4 下完成同一组任务，比较完成时间、周转时间、带权周转时间
  - 判断某算法是否适合批处理、分时或实时系统，并解释原因
  - 说明 SJF 的饥饿问题如何用 HRRN 或动态优先级缓解
  - 对比 Linux、Windows、鸿蒙的调度对象与调度策略

## 成功证据
- 学生能独立画出正确的甘特图，并说明每一步选择该作业/进程的理由
- 学生能正确计算平均等待时间、平均周转时间、带权周转时间
- 学生能解释 SJF 的饥饿机制，以及 HRRN 或动态优先级为什么能缓解
- 学生能判断某算法适合批处理、分时或实时系统并给出因果解释
- 学生能用自己的话对比 Linux、Windows、鸿蒙的调度对象与策略
